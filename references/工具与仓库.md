# 工具与仓库

每个环节实际用什么，以 Skill 根目录 `config.json` 为准；下表是可选项。每个阶段需要动手时，先查对方是否已装对应 Skill；没装就按下面的话术引导，用户同意后再装。

## 引导安装的话术

> 这一步（{阶段}）要用 `{Skill}`，它负责 {用途}。仓库：{地址}。
> 安装命令：`{命令}`。要我帮你装吗？不装也可以，我用 {替代方式} 先顶上，效果会弱一些。

装之前说明：会写入哪个目录、要不要账号或 API Key、要不要联网上传数据。

**共同依赖**：FFmpeg（剪辑、渲染、抽帧都要）、Node.js 20+（Remotion / HyperFrames / OpenEdit）。

## 转录流程

1. **配凭证**（第一次）：按下面「火山引擎开通」拿到 API Key，让用户自己设成环境变量 `VOLC_ASR_API_KEY`（或填进 Skill 根目录 `config.json` 的 `volcAsr.apiKey`，该文件不进 git）。密钥不发进对话。资源 ID 默认 `volc.seedasr.auc`、模型默认 `bigmodel`，控制台给的不一样时再用 `VOLC_ASR_RESOURCE_ID`、`VOLC_ASR_MODEL` 改。
2. **转录**（在项目文件夹里执行，要几分钟，放后台跑）：
   ```
   python <Skill 目录>/scripts/volc_transcribe.py "素材/原片.mov" --out "源文件/转录/火山逐词转录.json" --preview "源文件/转录/转录_分句预览.txt"
   ```
   脚本会：FFmpeg 抽 16k 单声道音频 → 提交火山 → 每 2 秒查一次结果 → 写逐词 JSON（停顿用 `isGap` 空隙词表示）→ 停顿 ≥0.35 秒断句写分句预览（每行 `序号 [起-止秒] 这句话 (停 X 秒)`）。输出文件已存在时不覆盖。
3. 跑完看输出的字数、时长对不对得上原片，再拿分句预览对定稿口播稿，写删剪提案（SKILL.md ④）。

## 人脸检测

**为什么要测**：全屏真人的镜头里，文字、卡片、字幕（连同它们的背景）绝对不能压到脸；缩成右下小圆时，裁切中心要对准脸，不能切掉下巴。凭感觉摆，人一动就会压脸或切脸，所以用实测结果。

**什么时候跑**：⑤ 剪完口播、拿到口播底片之后跑一次；写 ⑧ 镜头表之前必须有结果。重新剪了口播、换了素材，就重跑。

**怎么跑**：
```
python <talkcraft 目录>/scripts/face_bbox.py "源文件/口播剪辑/口播底片.mp4" "源文件/人脸安全区.json" --step 1.0
```
每秒抽 1 帧，用 OpenCV 自带的轻量人脸模型（YuNet）在本机 CPU 上检测，不联网上传。4 分钟左右的视频大约跑 1 分钟。

**结果怎么看**（坐标都是原片像素，左上角为原点，`[x, y, 宽, 高]`）：
- `detect_rate`：检出率。低于 90% 说明很多帧没认出脸（侧脸、遮挡、太暗），要抽帧看一眼。
- `union_face`：整期里脸出现过的范围合起来。
- `safe_zone`：在 `union_face` 基础上，头顶多留 60%（算上头发）、左右各多留 20%，四周再加 30 像素。

**结果怎么用**：
- **全屏真人镜头**：文字、卡片、字幕及其背景，任何时刻都不进 `safe_zone`；镜头表里写清每张卡放在安全区的哪一侧。脸部特写的原片，安全区会占掉大半个画面，内容只能放在上方和底部，排分镜时要预先考虑。
- **右下小圆头像**：用 `union_face` 的中心定裁切中心，按脸的高度定缩放，让额头到下巴完整落在圈里；样板镜里再看一眼确认。

## 火山引擎开通

第一次转录时带用户走一遍，之后复用。

相关链接：
- 豆包语音控制台（建应用、开通服务、拿 API Key）：https://console.volcengine.com/speech/app
- 豆包语音文档（接口说明）：https://docs.volcengine.com/docs/6561
- 计费说明（免费额度、价格）：https://docs.volcengine.com/docs/6561/1359369

1. **开通**：注册并登录火山引擎 → 进入「豆包语音」控制台 → 创建一个应用 → 给应用开通「录音文件识别」（大模型版）的免费试用。
2. **拿凭证**：脚本用的是新版控制台的 **API Key**（请求头 `X-Api-Key`）。如果控制台只给了 APP ID + Access Token（旧版鉴权），脚本不能直接用，按控制台指引换成 API Key。
3. **存凭证**：让用户自己填进环境变量或本地配置文件（不进 git）；**不要让用户把密钥发在对话里**，AI 也不把密钥写进代码、日志或文档。
4. **上传前征得用户同意**：音频会上传到火山引擎。
5. **额度**（以官方控制台和计费说明为准，规则可能调整）：
   - 官方计费说明：创建应用后有免费试用额度，录音文件识别 20 小时，有效期半年；免费试用要在控制台手动开启。
   - 作者经验：一个账号可以建多个应用（约 10 个），每个应用各有一份 20 小时；一个用完再建下一个。官方文档没写明额度是按应用还是按账号算，以控制台实际显示为准。
   - 免费额度用完后按量付费，价格看官方计费说明。

## 选画面工具的思路

- 用户已经装了哪个就优先用哪个，不为了换工具重新装一套。
- 想要成套"商用级"动效卡、按镜头表施工 → `video-talkcraft`（卡库复制进工程后只换皮，时长和缓动参数不动）。
- 习惯 React、要复杂数据可视化 → Remotion。
- 习惯 HTML、要快速出字幕和标题卡 → HyperFrames。
- Remotion 依赖只装一份：用 `video-talkcraft/runtime/` 里按版本锁定的那套（在该目录 `npm ci`，再 `npx remotion browser ensure` 下载无头浏览器）。每期工程的 `node_modules` 链过去，不在工程里 `npm install`；升级 runtime 先问用户，制作中途不升级。
- Windows 上链接用目录联接（PowerShell `New-Item -ItemType Junction`），不要用 git-bash 的 `ln -s`，后者可能把几百 MB 依赖整份复制一遍。
